# 如何結合兩個互相對立的歸一化值

當兩個歸一化（0-1 範圍）的值存在互相**對抗**或**拮抗**的關係時，我們需要使用特定的數學模型來體現它們之間的「拉鋸戰」。選擇哪種模型取決於您希望結合後的值代表什麼意義。

以下是幾種常見的結合方法，適用於不同的分析目標。

---

## 方法一：計算「優勢差」 (Dominance Score)

此方法用於衡量一個值相對於另一個值的「領先」程度。

**核心思想：**
直接用一個值減去另一個值。結果範圍為 -1 到 1，其中 0 代表勢均力敵。為了將結果保持在 0-1 範圍內，可以進行線性轉換。

**歸一化公式：**
```
normalized_dominance = (v1 - v2 + 1) / 2
```
- **1**: `v1` 完全佔優
- **0.5**: `v1` 和 `v2` 勢均力敵
- **0**: `v2` 完全佔優

**使用情境：**
- **股市多空指標**：`v1` 是看漲情緒，`v2` 是看跌情緒。
- **遊戲攻防評分**：`v1` 是攻擊力，`v2` 是防禦力。

**Python 範例：**
```python
# v1: 攻擊方力量 (0-1)
# v2: 防守方力量 (0-1)
v1 = 0.8
v2 = 0.3

# 計算歸一化後的優勢分數 (0 to 1)
normalized_dominance = (v1 - v2 + 1) / 2
# 結果: 0.75 (偏向 v1)
print(f"歸一化優勢分數: {normalized_dominance:.2f}")
```

---

## 方法二：衡量「衝突強度」或「僵持程度」

此方法用於衡量兩個值是否都處於「高度活躍」的對抗狀態。

### 1. 衝突強度 (Conflict Intensity)
**核心思想：**
當兩個值都很大時，衝突最激烈。

**公式：**
```
conflict_intensity = v1 * v2
```
- 結果越接近 1，代表雙方都投入巨大，競爭激烈。
- 結果越接近 0，代表一方或雙方投入很少，衝突不激烈。

### 2. 僵持程度 (Stalemate Score)
**核心思想：**
當兩個值大小越接近，代表戰況越膠著。

**公式：**
```
stalemate_score = 1 - abs(v1 - v2)
```
- 結果越接近 1，代表雙方實力越接近，高度僵持。
- 結果越接近 0，代表一方碾壓，無僵持。

**使用情境：**
- **系統資源競爭**：分析不同任務是否在同時搶佔資源 (`conflict_intensity`)。
- **遊戲平衡分析**：分析一場比賽的精彩程度或膠著程度 (`stalemate_score`)。

**Python 範例：**
```python
v1 = 0.9
v2 = 0.85

# 計算衝突強度
conflict_intensity = v1 * v2
print(f"衝突強度: {conflict_intensity:.2f}") # 結果: 0.77

# 計算僵持分數
stalemate_score = 1 - abs(v1 - v2)
print(f"僵持分數: {stalemate_score:.2f}") # 結果: 0.95
```

## 方法三：計算「權衡結果」 (Trade-off Outcome)

此方法常用於計算一個「攻擊」對抗一個「防禦」後的最終成功率或效益。

**核心思想：**
將其中一個對抗值**反轉** (invert)，使其目標與另一個值一致，然後再進行結合（如平均）。例如，`v2` 的防禦力越高，對 `v1` 的攻擊越不利。那麼 `(1 - v2)` 就代表了「防禦的脆弱性」。

**公式 (以平均為例)：**
```
outcome = (v1 + (1 - v2)) / 2
```

**使用情境：**
- **攻擊成功率**：`v1` 是攻擊點數，`v2` 是防禦點數。
- **市場滲透潛力**：`v1` 是產品吸引力，`v2` 是競爭產品強度。

**Python 範例：**
```python
# v1: 你的攻擊力
# v2: 敵人的防禦力
v1 = 0.7
v2 = 0.8 # 敵人防禦很強

# v2 的反轉值，代表「防禦的脆弱性」
v2_weakness = 1 - v2 # 結果為 0.2

# 結合我方攻擊力和對方防禦脆弱性
outcome = (v1 + v2_weakness) / 2
print(f"綜合結果/成功率: {outcome:.2f}") # 結果: 0.45
```

---

## 總結

| 目標 | 方法 | 公式 | 意義 |
| :--- | :--- | :--- | :--- |
| **判斷誰佔優勢** | 優勢差 | `(v1 - v2 + 1) / 2` | 0.5=平衡, 1=v1勝, 0=v2勝 |
| **衡量衝突激烈度** | 衝突強度 | `v1 * v2` | 越高代表雙方都投入巨大，競爭激烈 |
| **衡量僵持程度** | 僵持分數 | `1 - abs(v1 - v2)` | 越高代表雙方實力越接近，戰況膠著 |
| **計算綜合結果** | 權衡結果 | `(v1 + (1 - v2)) / 2` | 結合一個正向指標和一個反向指標後的效益 |

選擇哪種公式取決於您的具體應用場景和分析目標。
